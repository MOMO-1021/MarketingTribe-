Place the compiled MarketingTribe.apk file in this folder:
d:\Marketing Tribe Project(Both Web & Android)\Chatting Platform for Marketers-Web Version\public\downloads\MarketingTribe.apk

When you build the APK in Android Studio (Build -> Build Bundle(s) / APK(s) -> Build APK(s)), copy the generated app-debug.apk or app-release.apk here and rename it to MarketingTribe.apk.
Users clicking "Download Android App" on the website will instantly download this file directly to their phones.
